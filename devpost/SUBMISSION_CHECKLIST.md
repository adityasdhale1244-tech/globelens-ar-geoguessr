# Submission checklist

## Build and policy
- [ ] Select Gaming track.
- [ ] Confirm division eligibility against the project's actual start date and event rules.
- [ ] Build for the required Meta Quest device and validate the event's policy requirements.
- [ ] The player can complete a round seated, without room-scale movement.
- [ ] Hand-first interaction works end-to-end without pairing a controller; controller fallback is optional.
- [ ] Pause/resume and quick start/exit flow work.
- [ ] No broken network dependency or exposed secret in the judged experience.

## Project and assets
- [ ] Unity scene is committed and opens on the documented Unity version.
- [ ] Meta XR setup and package versions are documented accurately.
- [ ] Panoramas, audio, fonts, and other assets are licensed/attributed.
- [ ] Timer, map pin, scoring, reveal, progression, final score, and replay tested on device.
- [ ] Public source repository is accessible to judges.

## Submission materials
- [ ] Upload the APK to a new Meta VR Developer Dashboard release channel named `Competition`.
- [ ] Create an Invite URL and test that a judge can access the Project.
- [ ] Record and publish a public demo video under three minutes.
- [ ] Submit name, tagline under 140 characters, Gaming track, eligible division, truthful description, and all required links.
- [ ] Keep the build available and do not alter the submission after the entry deadline.
