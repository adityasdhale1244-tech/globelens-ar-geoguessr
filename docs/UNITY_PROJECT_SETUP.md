# GlobeLens Quest — 3D atmosphere and map interaction guide

See [PREMIUM_SCENE_SETUP.md](PREMIUM_SCENE_SETUP.md) for the full scene layout and [ADVANCED_3D_AND_MAP_LOOP.md](ADVANCED_3D_AND_MAP_LOOP.md) for destination cues, ambience, map preview/commit/reveal interaction, setup, comfort, and testing guidance.

The Unity Editor scene generator is in `Assets/GlobeLens/Editor/GlobeLensSceneBuilder.cs` and appears under **GlobeLens → Create Demo Scene** after importing the repository's Assets folder into Unity and importing TMP Essential Resources.

This repository contains source and docs. You still need to add licensed panoramic images, optional cue prefabs, Meta XR rig/hand UI integration, and verify the project on Quest hardware.
